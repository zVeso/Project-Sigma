# League of Legends Boosting Service — Документация

Този документ описва всяка страница, дизайна и използваните ресурси.

## Страници
- Home (index.html): Хиро секция, бутони, видео, предимства.
- Services (services.html): 4 услуги с заглавие, описание и изображение.
- Pricing (pricing.html): Таблица с рангове и цени, hover ефект.
- How It Works (how-it-works.html): Номерирани стъпки с леки анимации.
- About (about.html): История, опит, гаранции и тематично видео.
- Contact (contact.html): Формуляр с Name, Email, Rank, Message + Discord линк.
- Sources (sources.html): Източници и кредити.

## Дизайн
- Цветова схема: тъмно синьо/лилаво, златен акцент.
- Шрифт: Montserrat (Google Fonts).
- Икони: Font Awesome.
- Навигация: хоризонтално меню, активна страница – златен фон.

## Изисквания
- 6+ HTML страници (реализирани са 7).
- Единен CSS файл (`css/styles.css`).
- Таблица (Pricing).
- Формуляр (Contact).
- Видео (Home, About).
- Хипервръзки и еднакъв хедър/футър.
- Лого (SVG в `assets/logo.svg`).
- Източници (Sources страница).

## Бележки
- Формулярът е примерен (`action="#"`) и не изпраща данни към бекенд.
- Изображенията са от Unsplash чрез външни URL.
- Видео е вградено от YouTube (iframe).
